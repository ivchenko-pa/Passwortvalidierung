## Password Validator

The program to verify password's validity based on predefined requirements.

## Requirements
Provided password should:
- be minimum 8 characters long.
- contain at least one digit (0–9).
- contain uppercase and lowercase letters [A-Z,a-z].
- be Not in a list of common/weak passwords: "helloWorld2000", "SuperJava15", "Neuefische2026"
